# 베릴로그 기반 오토 도어록 시스템

<br>

## 📝 프로젝트 개요
* **수행 기간:** 2023. 04. 03. ~ 2023. 05. 31. (경희대학교)
* **프로젝트 목표:** Verilog HDL 및 FSM을 활용해 보안 기능이 강화되고 세 구역(출입문, 세대, 경비실) 간 통신이 가능한 오토 도어록 시스템 개발
* **주요 내용:**
  * **출입문**: 비밀번호 입력/재설정, 입력 제한, 세대 및 경비실 호출 기능
  * **세대**: 방문자 호출 응답 및 경비실 연락 기능
  * **경비실**: 방문자 기록 및 출입문 원격 제어 기능
  * 세 구역의 독립 모듈을 연결하여 유기적인 상호작용이 가능한 시스템 구축
<br>

---

## 👤 나의 역할 및 수행 업무
* **담당 역할:** 프로젝트 리더, 시스템 아키텍처 설계, 탑 모듈 개발 및 시뮬레이션 검증
* **수행 업무:**
    * **FSM 기반 설계**: 각 모듈의 FSM(Finite State Machine) 설계 및 시스템 아키텍처 구축
    * **탑 모듈 구현**: 하위 모듈(출입문 2개, 세대 1개, 경비실 1개) 간의 인터페이스 정의 및 통합 로직 구현
    * **테스트 벤치 작성 및 시뮬레이션**: 시나리오 기반의 Test Bench 코드를 작성해 기능 검증 수행
    * **일정 및 진행 관리**: 전체 개발 일정 관리, 회의 주도 및 팀원 간 소통 담당

## ⚙️ 시스템 아키텍처

## 🔍 트러블슈팅 및 회고

#### 📌 Case #1. 모듈 통합 과정에서의 변수명 충돌 및 인터페이스 불일치
* **문제 상황:** 개별 구현된 하위 모듈들을 탑 모듈에서 통합할 때, 신호 연결이 되지 않거나 컴파일 에러가 다수 발생
* **원인 분석:** 설계 초기 단계에서 `코딩 스타일 가이드(명명 규칙)`를 정의하지 않아, 팀원 간 서로 다른 변수명을 사용하여 포트 맵핑 시 혼선 발생
* **해결 방법:**
  * 각 하위 모듈의 인터페이스를 일일이 대조하여 명명 규칙에 맞게 수정하는 리팩토링 수행
  * 신호의 방향(Input/Output)과 데이터 폭을 재정의하여 탑 모듈에서의 포트 연결 완성
  * 이후 진행된 프로젝트에서는 규칙 정의를 최우선 순위로 설정(공통 규칙 문서화의 중요성)
